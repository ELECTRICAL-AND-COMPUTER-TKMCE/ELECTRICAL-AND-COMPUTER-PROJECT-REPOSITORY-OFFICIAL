# Templates

This folder contains reusable academic templates for the Electrical and Computer Project Repository Official.

The templates are intended to help students quickly prepare common academic documents such as seminar reports, presentations, project reports, and related submission materials.

---

## Folder Structure

```text
TEMPLATES/
├── README.md
└── SEMINAR/
    ├── SEMINAR_REPORT/
    └── SEMINAR_LATEX_PPT/
````

---

## Available Template Categories

### 1. Seminar Templates

The `SEMINAR` folder contains templates related to seminar submissions.

```text
SEMINAR/
├── SEMINAR_REPORT/
└── SEMINAR_LATEX_PPT/
```

#### SEMINAR_REPORT

Contains the LaTeX seminar report template.

Typical contents may include:

```text
report_template.tex
TKM_LOGO.png
README.md
SEMINAR_REPORT.zip
```

#### SEMINAR_LATEX_PPT

Contains the LaTeX Beamer seminar presentation template.

Typical contents may include:

```text
presentation_template.tex
README.md
SEMINAR_LATEX_PPT.zip
```

## How to Use

1. Open the required template folder.
2. Download the `.zip` file or individual template files.
3. Upload the files to Overleaf.
4. Edit the placeholders such as title, name, roll number, department, date, and topic details.
5. Recompile and download the final PDF.

---

## Notes

* Keep required image files, such as college logos, in the same folder as the LaTeX file.
* Do not rename image files unless the corresponding LaTeX code is also updated.
* Templates are general-purpose and can be reused for different seminar or project topics.
* Students may customize the content according to department or faculty instructions.

---

## Contribution Guidelines

When adding a new template:

1. Create a clearly named folder.
2. Include the editable source file.
3. Add a `README.md` explaining how to use the template.
4. Add a `.zip` version if students need direct download support.
5. Avoid uploading unnecessary temporary files.

Recommended files to avoid:

```text
*.aux
*.log
*.out
*.toc
*.synctex.gz
```
