# Electrical and Computer Project Repository Official

Centralized project hub for Electrical and Computer students to upload, browse, manage, and showcase academic projects with GitHub repository support, documentation links, structured submissions, and admin review workflow.

## Official Website

Website: https://er-project-hub.vercel.app/

Students can use the website to upload and access project files easily without using terminal commands or Git commands.

## About

Electrical and Computer Project Repository Official is built to collect, organize, and preserve student projects from the Electrical and Computer departments.

The platform helps students submit project details, GitHub repository links, project reports, documentation, and related files in a structured way. It also helps faculty members and future batches browse previous projects, understand earlier work, and use them as references.

## Main Features

- Student project upload system
- GitHub repository integration
- Pull request based submission workflow
- Automatic upload branch creation
- Admin review and workflow support
- Repository file browsing through the website
- Project report and documentation link support
- Organized project structure by batch, semester, category, and team
- Simple web interface for students without Git command usage

## Website Workflow

1. Open the official website.
2. Go to the upload page.
3. Fill in the project details.
4. Upload project files or add documentation links.
5. Submit the project.
6. The backend creates a GitHub branch.
7. A pull request is created automatically.
8. GitHub Actions can review or auto-merge valid uploads.
9. The project becomes available in the repository.
10. Students and faculty can view files through the website.
